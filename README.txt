CAMPUS CONTROL - PWA (madaxbanaan / independent)

AF SOMALI
1. Fur zip-ka (Unzip) si aad u hesho folder-ka "campus-control-pwa".
2. Tag https://app.netlify.com/drop  (ama Cloudflare Pages / GitHub Pages).
3. Soo jiid (drag) folder-ka oo dhan bogga. Waxaad heli doontaa link https:// ah.
4. Ku fur linkigaas Chrome-ka taleefankaaga. Taabo menu (⋮) -> "Install app" ama "Add to Home screen".
5. Hadda waxay u shaqaysaa sida app, xitaa internet la'aan.

Xusuusin:
- Xogtaada waxay ku kaydsan tahay taleefankaaga oo keliya, ma tagto server.
- Isticmaal "Export backup" toddobaad kasta.
- Ha tirtirin Chrome "site data".

ENGLISH
1. Unzip, 2. drag the folder to https://app.netlify.com/drop, 3. open the https link on your phone in Chrome,
4. menu -> Install app / Add to Home screen. Works offline after the first visit.
Files: index.html (the app), manifest.webmanifest, sw.js (offline cache), icons/.
